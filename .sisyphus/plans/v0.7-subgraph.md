# v0.7.0 — SubGraph Operator Design

## Overview

`.agrc` bundle 可作为一个节点嵌入另一个图。子图拥有独立上下文。端口由 loader 从子图自动解析，使用方式与其他节点完全一致。

---

## 1. Protocol — 零额外学习成本

```json
{
  "id": "translator",
  "type": "SubGraph",
  "label": "翻译 Agent",
  "config": {
    "bundle": "translator.agrc"
  }
}
```

**只有 `bundle` 一个配置项。** 不需要声明 inputs/outputs。

---

## 2. 端口自动推导

Loader 加载父图时，遇到 `SubGraph` 节点，自动解析子图：

```
子图 translator.agrc/flow.json:

  [Trigger: trigger_1]
       │ payload        ← SubGraph 的 input port
       ▼
  [Prompt_Builder]
       │ messages
       ▼
  [LLM_Task]
       │ response, usage
       ▼
  [Log: log_1]          ← 终端节点（无出边）
       │ message        ← SubGraph 的 output port

自动推导结果:
  SubGraph input ports:  ["payload"]      (Trigger 的输出)
  SubGraph output ports: ["message"]      (终端节点 Log 的输出)
```

推导规则：
- **Input ports** = 子图所有 Trigger 节点的 output ports
- **Output ports** = 子图所有终端节点的 output ports（终端节点 = 无出边的节点）

---

## 3. 与 Edges 完全一致

父图用 SubGraph 和其他节点没有区别：

```json
{
  "nodes": [
    {"id": "t", "type": "Trigger"},
    {"id": "sub", "type": "SubGraph", "config": {"bundle": "child.agrc"}},
    {"id": "log", "type": "Log"}
  ],
  "edges": [
    {"source": "t",    "sourcePort": "payload",  "target": "sub", "targetPort": "payload"},
    {"source": "sub",  "sourcePort": "message",  "target": "log", "targetPort": "message"}
  ]
}
```

loader 解析 `child.agrc` → 发现 Trigger 输出 `payload`，终端 Log 输出 `message` → SubGraph 端口 = `payload` in / `message` out。

## 4. 执行流程

```python
class SubGraphOperator(IOperator):
    """执行嵌套 .agrc agent。"""

    name = "builtin.subgraph"
    version = "1.0.0"

    def get_input_ports(self) -> list[Port]:
        # 运行时由 _resolve_ports() 注入
        return self._input_ports

    def get_output_ports(self) -> list[Port]:
        return self._output_ports

    async def execute(self, inputs: dict, context: ExecutionContext) -> dict:
        # 1. 加载子图
        child_engine = create_child_engine(self.bundle_path)

        # 2. 解析模板：把 inputs 中的 {{}} 替换为父图上下文
        resolved = resolve_inputs(inputs, context)

        # 3. 创建子图独立 StateManager
        child_state = StateManager()
        child_state.initialize(...)
        child_state.set_global("_parent_context", context)  # 只读

        # 4. 注入到子图的 Trigger
        child_engine._state = child_state

        # 5. 运行子图
        result = await child_engine.execute(resolved, mode="sync")

        # 6. 提取子图终端节点输出，返回
        return extract_terminal_outputs(child_engine)
```

## 5. Context Isolation

```
父图上下文                          子图上下文
┌─────────────────┐               ┌─────────────────┐
│ user_query: "Hi" │─── 注入 ──→  │ payload: "Hi"    │
│ config: {...}    │               │ llm_response: .. │
│ _vfs_perms: rwx  │               │ _parent: {ref}   │  ← 只读引用
└─────────────────┘               └─────────────────┘
         ↑                               │
         └────── 返回: {message: "..."} ←─┘ 终端节点输出
```

- 子图有独立的 `_state`、`_global`、`_local`
- 可以通过 `{{parent.xxx}}` 模板引用父图上下文
- 子图修改不影响父图
- 只有终端节点的输出返回到父图

---

## 6. Bundle Resolution

```
解析顺序:
1. 相对路径:   bundle="child.agrc"        → 相对于父 bundle 所在目录
2. 绝对路径:   bundle="/path/to/x.agrc"    → 直接用
3. 嵌入路径:   bundle="sub/child.agrc"     → 父 bundle 内 sub/ 目录
```

---

## 7. Packing Integration

`agenarc pack` 扫描 SubGraph 节点，自动收集并嵌入子图：

```
agenarc pack my_agent/ my_agent.agrc
  → Scanning flow.json
  → Found SubGraph: child.agrc
  → Embedding child.agrc → my_agent.agrc/sub/child.agrc/
  → Packed: my_agent.agrc
```

运行时优先从 `sub/` 目录加载嵌入的 bundle。

## 8. 循环引用检测

```python
def _check_recursive(bundle_path, visited=None):
    visited = visited or set()
    resolved = str(bundle_path.resolve())
    if resolved in visited:
        raise SubGraphError(f"Recursive reference: {resolved}")
    visited.add(resolved)
    for node in load_subgraph_nodes(resolved):
        if node.type == "SubGraph":
            _check_recursive(node.config["bundle"], visited.copy())
```

---

## 9. Error Handling

| 场景 | 行为 |
|------|------|
| 子图 bundle 不存在 | `SubGraphError: Bundle not found` |
| 子图加载失败 | `SubGraphError: Failed to load` |
| 子图执行失败 | 走父图 `errorNode` 或 Abort |
| 循环引用 | 加载时报错，不等到运行时 |
| 子图无 Trigger | `SubGraphError: No trigger node` |
